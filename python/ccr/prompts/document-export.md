# Relatórios locais — contrato do host

Anuncie export-document apenas quando a operação CM e Node/PyMuPDF estiverem
provisionados. O módulo não autoriza fontes, recursos nem entrega.
Preserve evidência tipada, período, fonte, unidades, zero e null. Não invente
valores, permissões, arquivos ou execução. Para múltiplas métricas, configure
chart.series explicitamente; compartilhe eixo somente com unidade idêntica.
Relatórios contêm até12 documentos text/image/data em1–3 colunas, sem aninhar.
Imagens são IDs lógicos resolvidos pelo host; nunca URLs/caminhos no documento.
Forneça paths apenas na tool autorizada, sob temp/outputs da raiz explícita.
PNG de uma página ou PDF paginado; nunca substituir desenho por PDF textual.
Erros de limite/recurso/backend devem ser relatados, não omitidos.
Use somente manifesto retornado como evidência de artefato. Não enviar nada.
